# 🚖 Uber Trip Analysis Dashboard (Power BI)

## 📌 Project Overview

The **Uber Trip Analysis Dashboard** is an interactive Power BI project designed to analyze booking trends, revenue generation, trip distance, cancellations, and vehicle performance. The dashboard provides actionable insights into Uber ride operations through dynamic visualizations, KPIs, and navigation-enabled report pages.

The project helps stakeholders monitor ride performance, identify booking patterns, evaluate revenue metrics, and make data-driven decisions.

---

## 🎯 Objectives

* Analyze overall booking performance.
* Track revenue and trip distance metrics.
* Compare completed and lost bookings.
* Evaluate vehicle category performance.
* Provide an intuitive and interactive user experience.
* Enable quick navigation between dashboard sections.
